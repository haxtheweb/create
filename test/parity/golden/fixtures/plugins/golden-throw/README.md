# golden-throw

A parity test fixture for the [haxtheweb/create](https://github.com/haxtheweb/create) golden suite, not a plugin anyone installs.

It subscribes to every core hook the golden cases' routes fire and throws from each one. The plugin spec says a hook error is logged and the operation goes on with the previous subject (only an explicit veto stops it), so the golden suite runs with it switched on (`--throwing-plugin`) and every case must still match its committed snapshot on haxcms-nodejs and haxcms-php: a broken plugin never changes or breaks a save.
